Exemple de programme

Exemple de démonstration à remplacer par votre propre code.
// Exemple de démonstration
const int moteur = 9;
int distance = 0;

void setup() {
  pinMode(moteur, OUTPUT);
}

void loop() {
  if (distance > 20) {
    analogWrite(moteur, 150);
  } else {
    analogWrite(moteur, 0);
  }
}
